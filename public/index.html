FAQ

Frequently Asked Questions

What types of documents can Visiolog process?
Visiolog processes financial ledgers, tax assessment forms, printed invoices, store receipts, tabular logs, lab registries, bank statements, census forms, and handwritten tables in PNG, JPG, or WebP formats.
How is my data protected during processing?
Document images are processed in volatile server memory with zero persistent image retention. Extracted data is never shared with third parties and is automatically purged from processing buffers once the conversion completes.
Can I edit extracted tables before downloading?
Yes. The built-in 2D spreadsheet editor lets you modify any cell, add or delete rows, adjust column headers, and review numeric values before downloading to Excel or CSV.
Can I self-host Visiolog on my own server?
Yes. Visiolog is fully self-hostable as a Docker container on any Linux VPS, Raspberry Pi, or cloud instance. The local standalone mode requires only Node.js and a Gemini, OpenRouter, or Ollama inference key — no Supabase or external database required.
Does Visiolog support continuous batch-appending to a master sheet?
Yes. The Master Sheet Reconciliation engine appends successive document batches into a single consolidated project spreadsheet with automatic header alignment and deduplication.
