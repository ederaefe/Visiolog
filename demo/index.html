FAQ

Frequently Asked Questions

What types of documents can Visiolog process?
Visiolog processes financial ledgers, tax assessment forms, printed invoices, store receipts, tabular logs, registries, and scanned documents in PNG, JPG, or WebP image formats.
How is my data protected during processing?
Your files are processed in secure temporary memory buffers with zero persistent image retention and automatic memory purges once extraction completes.
Can I edit extracted tables before downloading?
Yes. The built-in spreadsheet editor lets you edit any cell value directly in an interactive grid layout before exporting to CSV.
