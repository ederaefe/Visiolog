Configuration

Vision engine settings, API credentials, prompts, and application reset.

Live Demo Notice These custom API key settings power the client-side demonstration, allowing users to evaluate in-browser vision processing without creating an account or provisioning cloud infrastructure. In the full production Visiolog platform, API credentials, tenant encryption keys, and multi-tenant quotas are managed securely via Supabase PostgreSQL and Row Level Security. Read Real App Docs
1. Provider
Google Gemini

Choose which vision engine executes tabular document OCR. Credentials adapt dynamically.

2. Credentials

Enter your personal API key. It connects directly from your browser to the provider endpoint.

3. Model
Adaptable

Select or type any custom model ID, then test outbound connectivity to verify valid credentials.

4. Prompt

Customize instructions passed to the vision AI engine.

5. History

Visiolog saves extracted spreadsheets in browser memory. You can clear conversion history independently.

6. Reset Application
Danger

Wipes all local storage data: API credentials, custom endpoints, prompt rules, model preferences, and document history. This action cannot be undone.
