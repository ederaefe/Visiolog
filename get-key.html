How to Get an API Key

Visiolog operates 100% in your browser. To transcribe paper registries and logbooks into spreadsheets, connect your preferred vision provider. Follow the step-by-step guides below.

Google Gemini API Key

Best transcription accuracy for handwritten logbooks & receipts

Open AI Studio
1
Visit Google AI Studio

Go to aistudio.google.com/app/apikey and sign in with any standard Google account.

2
Click "Create API key"

Click the blue Create API key button in the top right. Select an existing Google Cloud project or choose Create API key in new project.

Google AI Studio > Get API key > [ + Create API key ]
3
Copy your Secret Key

A string starting with AIzaSy... will be generated. Click the copy icon.

Key: AIzaSyD9x8K... (39 characters) [Copy]
4
Paste Key into Visiolog Settings

Return to Visiolog Settings, select Google Gemini, paste your key into the API key field, and click Test.

Free Tier Quota: Google AI Studio provides a free tier with 15 requests per minute, which is more than enough for daily paper-to-spreadsheet conversions.
Caution: Do not confuse Google Cloud OAuth Client IDs (ending in .apps.googleusercontent.com) with API keys. Visiolog expects a direct REST API key starting with AIzaSy....
Ready to configure?
Head over to settings and paste your key.
Open Settings

OpenRouter API Key

Access Claude 3.5 Sonnet, Llama 3.2 Vision, Qwen 2.5 VL, and more

Open OpenRouter
1
Sign Up / Sign In on OpenRouter

Navigate to openrouter.ai/keys and log in.

2
Create a New Key

Click Create Key. Enter a label (e.g. Visiolog Workspace) and click Create.

OpenRouter > Keys > [ + Create Key ]
3
Copy your Secret Key

Copy the generated key starting with sk-or-v1-....

Free Vision Models: OpenRouter hosts free vision models like meta-llama/llama-3.2-11b-vision-instruct:free.
Have your OpenRouter key?
Switch provider to OpenRouter in settings.
Open Settings

Ollama (100% Offline Local Vision)

Run vision models locally on your GPU/CPU with zero external network traffic

Download Ollama
1
Install Ollama & Pull a Vision Model

Open your terminal or command prompt and pull a lightweight vision model:

ollama run llama3.2-vision
2
Configure Browser CORS Access

Because Visiolog runs in the browser, Ollama must allow web origins. Set the environment variable before starting Ollama:

Windows PowerShell: $env:OLLAMA_ORIGINS="*"
macOS/Linux: export OLLAMA_ORIGINS="*"
3
Connect in Visiolog Settings

In Settings, select Ollama (Local), confirm endpoint http://localhost:11434, and click Test.

CORS Required: If test fails with "Failed to fetch", ensure OLLAMA_ORIGINS="*" is configured and restart the Ollama service.
Ollama running locally?
Test your local connection in settings.
Open Settings

Custom OpenAI-Compatible Endpoint

Connect vLLM, LM Studio, Groq, Azure OpenAI, or self-hosted proxies

1
Locate your Base URL & Key

Ensure your endpoint supports OpenAI-compatible /v1/chat/completions with base64 vision image payloads.

2
Enter URL & Key in Settings

In Settings, select Custom Endpoint. Enter your custom server URL (e.g. https://api.groq.com/openai/v1/chat/completions), your API key, and your vision model name.

Have custom credentials?
Configure your custom endpoint in settings.
