Web Application Documentation

Comprehensive guide to using the Visiolog in-browser document extraction workspace, model configuration, and rendering engine.

1. In-Browser Architecture & Privacy

The Visiolog web edition runs 100% in your browser. No files, tokens, or transcribed data are ever stored on intermediary servers:

  • Client-Side Canvas Downsampling: Scanned documents are preprocessed in browser memory, scaling large photos to max 2048px to minimize token cost and memory overhead.
  • Direct API Dispatch: API calls connect directly from your browser to your selected provider endpoint (Google Gemini, OpenRouter, local Ollama, or custom OpenAI-compatible server).
  • Local Persistence: Configuration preferences, custom models, and conversion history are stored strictly in your browser's localStorage.

2. Configuring Model Providers

Navigate to the Settings page to set up your AI vision provider:

Google Gemini (Default)

Enter your Google Gemini API key. Click Auto-Detect Models to probe available models (e.g. gemini-2.5-flash, gemini-2.5-pro) or type any custom model ID into the combobox.

OpenRouter

Enter an OpenRouter key to access diverse multimodal vision models including meta-llama/llama-3.2-11b-vision-instruct and qwen/qwen-2.5-vl-72b-instruct.

Ollama (Local Private Inference)

Requires zero API keys. Ensure Ollama is running locally on port 11434 with multi-origin access:

export OLLAMA_ORIGINS="*"
ollama run llama3.2-vision

Custom Endpoint (OpenAI-Compatible)

Connect to private inference microservices, vLLM, or LM Studio by specifying a Base URL, optional API key, and model name.

3. Outbound Connection Testing

Before processing documents, click the Test Outbound Connection button in Settings:

  • Green Status: Confirms active network reachability, valid credentials, and model availability with reported latency.
  • Red Status / Diagnostics: Displays clear actionable error causes (e.g. invalid API key, network timeout, or CORS restriction) so you can adjust your configuration immediately.

4. Workspace & Dual Rendering Engine

The Workspace supports flexible data visualization and editing:

  • Table View (Spreadsheet Grid): Interactive 2D table with full contenteditable cell editing, dynamic row insertion (+ Row), and RFC 4180 CSV export.
  • Notes View (Structured Document): Formats tabular records into a human-readable Markdown/HTML document with section headings and bulleted items. Includes 1-click clipboard copy and Markdown export.
  • Batch Ingestion & Queue: Upload single or multiple documents. The queue list allows selecting any document for conversion.
  • Failsafe Retry: If an extraction encounters a rate limit or credential error, the image remains preserved in memory. Update your key or model in Settings and click Retry immediately without re-uploading.
