1. Client Architecture & Privacy

Visiolog is engineered with a client-first, zero-telemetry architecture. Document ingestion, compression, and spreadsheet rendering happen in your browser:

  • Client-Side Canvas Downsampling: High-resolution documents (such as 48MP smartphone photos) are scaled down proportionally to 2048px maximum dimension via HTML5 Canvas before dispatch.
  • Direct Provider REST Dispatch: API requests route directly from your browser to Google Generative Language REST endpoints, OpenRouter, or local Ollama.
  • Volatile Memory Buffer: Image buffers reside exclusively in browser RAM and are purged when documents are cleared.

2. Model Providers & Setup

Configure your AI vision engine on the Settings page:

A. Google Gemini

Connects directly to Google Gemini REST API. Click Detect in Settings to probe active models (gemini-2.5-flash, gemini-2.5-pro).

B. OpenRouter

Access open multimodal vision models via OpenRouter (meta-llama/llama-3.2-11b-vision-instruct, qwen/qwen-2.5-vl-72b-instruct).

C. Ollama (Local)

Run OCR locally on your GPU with zero cloud keys.

export OLLAMA_ORIGINS="*"
ollama run llama3.2-vision

D. Custom Endpoint

Connect to any OpenAI-compatible Vision API (vLLM, LM Studio, Together AI).

3. Outbound Connection Testing

In Settings, the Test button runs live diagnostic connectivity tests:

  • Diagnostic Ping: Sends a lightweight probe to verify credentials and endpoint availability.
  • Latency Metrics: Reports measured round-trip latency (e.g. 128ms).

4. Spreadsheet & Notes Engine

The Workspace provides dual rendering modes:

  • Table View: Full editable cells, column sorting, inline search filtering, row/column addition and removal.
  • Notes View: Generates structured Markdown and HTML summaries with instant clipboard copy.

5. Document CRUD & Multi-Format Exports

Visiolog provides complete client-side document management and multi-format exports:

  • Create: Upload document images, create blank spreadsheets, or load sample templates (Invoice, Logbook).
  • Read: Image zoom preview, multi-file queue manager, spreadsheet grid, structured notes.
  • Update: Document rename, inline cell/header editing, row/column mutations, live filter search, column sorting.
  • Delete: Queue item removal, active sheet clear, single history removal, bulk clear.
  • Exports:
    • Excel (.xlsx): Native binary spreadsheet generated via client-side SheetJS.
    • CSV (.csv): RFC 4180 standard comma-separated text.
    • JSON (.json): Structured array of key-value row records.
    • Markdown (.md): GitHub-style formatted table and structured notes.
    • Clipboard: Formatted TSV for instant pasting into Excel or Google Sheets.

6. Storage Schema & Data Wipe

All preferences and document histories reside in browser localStorage:

Storage Key Type Description
visiolog_theme String Theme preference ('light' | 'dark').
visiolog_provider String Active vision provider ('gemini' | 'openrouter' | 'ollama' | 'custom').
visiolog_model String Active model identifier.
visiolog_demo_gemini_key String Stored Gemini API key.
visiolog_workspace_history JSON Array Saved conversion records.

Type-to-Confirm Data Wipe Protocol

To sanitize all stored keys, endpoints, and history, navigate to Settings > Reset Application. Type delete my data into the confirmation field to unlock the Wipe Data button, which executes localStorage.clear() and restores factory defaults.

7. Troubleshooting & Diagnostics

  • HTTP 400 (Bad Request): Verify that the model supports vision/multimodal inputs.
  • HTTP 401/403 (Unauthorized): Check API credentials in Settings.
  • CORS Blocked: Set OLLAMA_ORIGINS="*" for local Ollama servers.
