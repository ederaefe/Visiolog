# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability within Visiolog, please do NOT create a public issue.

Instead, please send an email to the repository maintainers with:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected configurations.

We will acknowledge receipt within 48 hours and work with you to release a patch promptly.
